# 🔍 Windows Event Viewer

**Event Viewer** is a Windows administrative tool used to view and analyze events generated by the operating system, applications, and services.

It provides information that can help analysts investigate:

* User activity
* Authentication attempts
* System changes
* Application errors
* Service activity
* Security-related events
* Potential suspicious behavior

---

# 📂 Important Event Logs

### 1. Windows Logs → Security

Contains security-related events such as:

* Successful logons
* Failed logons
* Account management
* Privilege usage
* Process creation
* Account lockouts

This is one of the most important logs for **SOC and Windows security investigations**.

### 2. Windows Logs → System

Contains events generated by Windows system components.

Useful for investigating:

* Service activity
* Driver issues
* System startup/shutdown
* Hardware-related events
* System errors

### 3. Windows Logs → Application

Contains events generated by applications running on the system.

Useful for investigating:

* Application errors
* Application crashes
* Application behavior
* Software-related issues

# 🔑 Important Security Event IDs

| Event ID | Description                                  |
| -------: | -------------------------------------------- |
| **4624** | Successful account logon                     |
| **4625** | Failed account logon                         |
| **4634** | Account logoff                               |
| **4647** | User initiated logoff                        |
| **4672** | Special privileges assigned to new logon     |
| **4688** | New process created                          |
| **4720** | User account created                         |
| **4722** | User account enabled                         |
| **4725** | User account disabled                        |
| **4726** | User account deleted                         |
| **4732** | Member added to security-enabled local group |
| **4740** | User account locked out                      |
| **7045** | New service installed                        |

> Event IDs should always be analyzed in context. A single event does not automatically indicate malicious activity.

# 🕵️ Authentication Log Analysis

One of the main areas practiced in Event Viewer is authentication analysis.

### Example Investigation

A large number of **Event ID 4625** events from the same source may indicate repeated failed authentication attempts.

Investigation points include:

* Username
* Source IP address
* Logon type
* Time of event
* Target computer
* Number of failed attempts
* Whether a successful login occurred afterward

### Investigation Flow

```text
Failed Logon
     ↓
Identify Source
     ↓
Identify Target Account
     ↓
Check Number of Attempts
     ↓
Analyze Time Pattern
     ↓
Check Successful Logon
     ↓
Investigate Source IP
     ↓
Determine Whether Activity Is Suspicious
```

# ⚙️ Event Filtering

Event Viewer can be used to filter large amounts of log data and locate specific events.

Useful filtering criteria include:

* Event ID
* Date and time
* User
* Computer
* Log level
* Event source

Example:

```text
Security Log
      ↓
Filter Current Log
      ↓
Event ID: 4625
      ↓
Analyze Failed Logons
```
